# Iteration 1 frozen contracts and ownership
Lead owns config.py, db.py, contracts.py, migrations/bootstrap, main.py, knowledge.py, runner.py, gateway.py, telemetry.py, all root dependencies/locks/startup/docs.
Identity worker owns backend/app/identity.py and backend/app/connections.py. Connector worker owns backend/app/connectors/* (except existing __init__.py). Frontend worker owns frontend/src/*, index.html and Vite/TS config; requests dependency changes from lead.
No test files, frameworks, persistent verification scripts, mocks or evaluation harnesses. Only I1-01 through I1-10.

Backend conventions: SQLAlchemy sync Session from get_db; config via settings(). Authorization uses identity.current_user(Request, db dependency) -> db.User; identity.require_capability(user, name); User capabilities are strings user, builder, admin, auditor, additive. Export router in identity and connections. connections.access_context(db, user, connection_id) async -> contracts.AccessContext after owner/status/scope/credential validation and refresh. No browser-selected owner, token or role accepted. connectors.registry[provider] -> Connector; SourceError codes denied, unavailable, unsupported, scope_missing; denied/not found are indistinguishable externally. All connector reads independently enforce collection and provider permissions. No source text stored by adapters.

Frontend API prefix /api (Vite proxies localhost:8000); cookie session, fetch credentials same-origin. GET /auth/me -> {id,username,name,capabilities,csrf_token}; POST /auth/login {username,password} -> same; POST /auth/logout -> {ok:true}; all mutation calls send X-CSRF-Token and Origin except login (Origin required). Safe errors {detail: safe code}. GET /connections -> {connections:[{id,provider,identity_label,provider_subject,tenant_id,collection,status,checked_at}],availability:{drive:{configured,collection},confluence:{configured,collection}}}. POST /connections/{provider}/authorize -> {authorization_url}; OAuth GET /connections/{provider}/callback -> redirect app /?connection=connected or safe error. POST /connections/{id}/health -> safe identity/status; DELETE /connections/{id} -> {ok:true}.
GET /health -> safe readiness. GET /conversations -> array {id,title,created_at}; POST /conversations {title?} -> record. GET /conversations/{id} -> {id,title,created_at,messages:[{id,role,text,status,run_id,evidence_refs,created_at}]}. POST /conversations/{id}/messages {text} -> {run_id}; retry submits same user question fresh. GET /runs/{id} -> run summary; GET /runs/{id}/events?after=0 SSE events named stable type, JSON {run_id,event_id,timestamp,type,data}; POST /runs/{id}/cancel -> run summary. Types run_started,retrieval_started,retrieval_completed,answer_delta({text}),citation({evidence_id,label,provider}; metadata references only),usage({usage}),run_completed,run_failed({code}),run_cancelled. Terminal events end SSE. GET /evidence/{id}?run_id=... -> fresh authorized {id,title,excerpt,canonical_url,location,modified_at,fetched_at,provider,version,changed}. GET /activity -> own run summary array; GET /activity/{id} -> {run,events: redacted audit metadata}; GET /audit -> restricted metadata for auditor/admin only, without chats/excerpts/document refs. GET /knowledge/search?q=... -> fresh authorized evidence previews (no cache; signed-in user only).
Run summary {id,conversation_id,agent_id,agent_version,trace_id,status,created_at,finished_at,model_alias,usage,providers,limitations,error_code,latency_ms}. Unknown token/cost fields null. Source identities/scopes never imply wider collection access.
